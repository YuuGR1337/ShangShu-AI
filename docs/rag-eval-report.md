## 结论要点

- **Rerank 精排未生效**：+Rerank 与纯向量指标完全一致，说明本次评测期间精排处于降级/关闭状态（`rag.rerank.enabled=false` 或 rerank 模型不可用），trace 的 reranked 为 RRF 候选原序。启用 rerank（配置 `RAG_RERANK_*`）后重跑即可对比精排增益。
- 纯向量与纯关键词的召回互补性体现在 RRF 阶段相对两单路阶段的提升幅度。
- **Token 消耗**：检索链路 trace 未透出 token 计数（QueryRewrite 的 LLM 调用计入服务端 sys_llm_log），本报告暂无法统计，后续可在 retrieveWithTrace 中补充透出。
